## 🛡️ Security Check Matrix

| Check | Severity | Description |
|---|---|---|
| **Domain Purity** | `HIGH` | Verifies domain layer does not import Flutter, Supabase, Drift, or Dio. |
| **Row Level Security (RLS)** | `CRITICAL` | Asserts every generated table has strict tenant isolation policies (`auth.uid() = user_id`). |
| **Cleartext HTTP Traffic** | `HIGH` | Ensures `android:usesCleartextTraffic="false"` and iOS App Transport Security are active. |
| **Secure Token Storage** | `CRITICAL` | Asserts tokens are saved via Keychain / EncryptedSharedPreferences, NEVER plain SharedPreferences. |
| **Service Role Secrets** | `CRITICAL` | Scans client files to guarantee zero client-side leaks of Supabase `service_role` keys. |
| **App Store 5.1.1 Deletion** | `HIGH` | Confirms Account screen includes irreversible user data deletion triggering backend cleanup. |
