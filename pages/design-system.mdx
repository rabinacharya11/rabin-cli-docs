## 🌓 OLED Pitch-Black & M3 Palette

Rabin CLI dynamically generates tonal palettes from your brand seed color:

```dart
// Generated M3 ThemeData with OLED Pitch-Black surfaces
final darkTheme = AppThemeGenerator.generate(
  primaryColor: Color(0xFF4A6CF7),
  brightness: Brightness.dark,
  oledPitchBlack: true,
);
```

- **True Pitch-Black (`#000000`)** background on OLED screens for battery optimization and contrast.
- **Card Surfaces**: `surfaceContainer` with 16px radius and 15% opacity hairline borders.
- **Button Standards**: 52px minimum touch target height, 14px radius, 0 elevation.

## 🚀 10x Performance Patterns

### 1. Fine-Grained `ValueNotifier` & `ValueListenableBuilder`
Instead of rebuilding entire widget trees with `setState()`, Rabin CLI templates isolate leaf state changes:

```dart
class MySwitch extends StatefulWidget {
  const MySwitch({super.key});

  @override
  State<MySwitch> createState() => _MySwitchState();
}

class _MySwitchState extends State<MySwitch> {
  final _switchValue = ValueNotifier<bool>(false);

  @override
  void dispose() {
    _switchValue.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return ValueListenableBuilder<bool>(
      valueListenable: _switchValue,
      builder: (context, value, child) {
        return Switch(
          value: value,
          onChanged: (newValue) => _switchValue.value = newValue,
        );
      },
    );
  }
}
```

### 2. Isolated Widget Previews (`@Preview`)

```dart
import 'package:flutter/widget_previews.dart';

@Preview(name: 'Primary Button - Enabled', group: 'Buttons')

  return AppButton.primary(
    text: 'Continue',
    onPressed: () {},
  );
}
```
